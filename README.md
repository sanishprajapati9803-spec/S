# Meridian

**A Real-Time Collaborative Document Editing System**

## About the Project

Meridian is a web-based collaborative document editing system designed to help users create, edit, share, and manage documents 
together in real time. It aims to improve teamwork through collaborative editing, document sharing, comments, version history, 
and responsibility-based task management.

## Objectives

- Enable multiple users to collaborate on documents in real time.
- Provide document creation, editing, organization, and sharing.
- Support user roles and document access permissions.
- Improve collaboration through comments and discussion threads.
- Maintain document history and support recovery of previous versions.
- Provide an AI Writing Assistant for writing improvements.
- Support offline editing and synchronization.
- Help teams track responsibilities and task completion.

## Key Features

- **User Management:** Registration and authentication.
- **Document Management:** Create, edit, search, and organize documents.
- **Real-Time Collaboration:** Allow multiple users to edit a document simultaneously.
- **Presence Awareness:** Display collaborators and their editing activity.
- **Sharing and Permissions:** Control who can view or edit documents.
- **Comments and Discussions:** Enable feedback and communication.
- **AI Writing Assistant:** Provide writing suggestions, rewriting, summarization, and grammar improvements.
- **Version History:** Review and restore previous document versions.
- **Responsibility Management:** Assign tasks and track completion within a team.
- **Offline Support:** Allow document editing offline and synchronize changes when connectivity returns.
